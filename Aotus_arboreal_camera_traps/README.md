Aotus arboreal camera traps – Reproducible Code and Data
This repository contains all data, code, and output required to reproduce the analyses and figures of the study:
"Arboreal camera traps reveal new insights into flower feeding and reproductive timing in owl monkeys (Aotus vociferans)"
Submitted to Ecology & Evolution (2025).

🚀 How to Run the Analysis
Clone the repository:

git clone https://github.com/<your-username>/publications.git
cd publications/Aotus_arboreal_camera_traps
Open R/RStudio and set the working directory to this folder.
To reproduce Table S2:

source("R/01_tree_distances.R")
Outputs are saved automatically into:

output/tables/

🧩 Dependencies
Required R packages:
	•	geosphere
	•	sf
	•	ggplot2 (for later figures)
	•	dplyr (for data wrangling)
Install them via:

install.packages(c("geosphere", "sf", "ggplot2", "dplyr"))
